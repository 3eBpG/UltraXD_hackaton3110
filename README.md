# Дом

Мобильный сайт умного дома для жителей ЖК и управляющей компании. Житель подключает устройства, управляет ими и собирает нодовые сценарии; УК наполняет каталог моделей и готовит общедоступные шаблоны.

## Текущий проект

**[Актуальная спецификация продукта и MVP](docs/PRODUCT.md)** — сущности, экраны, процессы, графы, расписание, управление устройствами и приёмка. Зафиксирована 31 октября 2026 года.

Готового приложения пока нет. ИИ-код — пример для изучения, а не принятый прототип. Локальный ИИ-код не публикуем. Наличие прежних инструкций или результатов тестов не означает готовность текущего MVP.

При расхождении документов требования берём из `docs/PRODUCT.md`. Прежние планы, API и схемы данных требуют актуализации под нодовый граф и расписание.
