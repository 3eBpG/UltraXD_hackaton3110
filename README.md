# Дом

Бэкенд умного дома: устройства и их модели, эмуляторы, пользовательские автоматизации, проверка правил и история выполнения. Один локальный демонстрационный дом с ролями пользователя и администратора.

## Запуск

Python 3.11+, macOS/Linux или Windows с WSL. Из корня репозитория:

```bash
bash run-backend.sh
```

Открой http://127.0.0.1:8000/docs. Демо-логины и сгенерированные пароли — в `backend/data/demo-accounts.txt`. Они создаются при первом запуске.

Во втором терминале проверь полный путь через API:

```bash
.venv/bin/python -m backend.demo
```

Пример создаёт датчик, нагреватель и правило, проверяет изоляцию теста и настоящее изменение состояния эмулятора.
