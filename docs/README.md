## Материалы организаторов

Исходная документация и библиотека эмуляторов находятся в [ultraxd](ultraxd/). Начальная инструкция — [START.md](ultraxd/START.md), описание библиотеки — [README эмуляторов](ultraxd/emulators/README.md).

Команды в инструкциях команды выполняются из корня клонированного репозитория, если явно не указано другое. Адреса `localhost` относятся к компьютеру, на котором запущена соответствующая программа.

## Проверки и ограничения

При подготовке плана прошли 58 штатных локальных тестов. Дополнительно проверены учебная цепочка «протечка → лампа» и формирование публикации Ujin в режиме без сетевой отправки. Это не подтверждает доступность облачного стенда и его разрешений. Расписание на 24 часа — рабочее предложение, точный дедлайн уточняется у организаторов.
